# Quick guide media

The Health Check's Quick guide plays `quick-guide-PLACEHOLDER.mp4` with the captions in `quick-guide-PLACEHOLDER.vtt`. Both are placeholders, made so the player can be tested: a 12-second silent video and four captions.

To use the real video, add the MP4 and its WebVTT captions here and change the two imports at the top of `src/health-check/QuickGuide.jsx`.
